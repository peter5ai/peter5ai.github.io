# 字体统一改为微软雅黑计划

## Summary
将网站所有字体统一改为微软雅黑（Microsoft YaHei），保持字体大小不变，只改变字形。

## Current State Analysis

### 当前字体设置
- **标题字体 (`--font-serif`)**: 'Noto Serif SC', 'Playfair Display', serif
- **正文字体 (`--font-sans`)**: 'Noto Sans SC', 'Inter', -apple-system, BlinkMacSystemFont, sans-serif
- **字体引用**: Google Fonts CDN（Noto Sans SC 和 Noto Serif SC）

### 使用情况
- `--font-serif` 使用约13处（主要用于标题）
- `--font-sans` 使用约3处（用于正文和正文段落）

## Proposed Changes

### 修改文件: `/workspace/index.html`

#### 1. 修改 CSS 字体变量定义（第48-49行）
**当前代码:**
```css
--font-serif: 'Noto Serif SC', 'Playfair Display', serif;
--font-sans: 'Noto Sans SC', 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
```

**修改为:**
```css
--font-serif: 'Microsoft YaHei', sans-serif;
--font-sans: 'Microsoft YaHei', sans-serif;
```

#### 2. 移除 Google Fonts 引用（第8行）
**原因:** 不再需要加载 Noto Sans SC 和 Noto Serif SC
**操作:** 删除以下行:
```html
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&family=Noto+Sans+SC:wght@400;500;600&family=Noto+Serif+SC:wght@400;600;700&family=Playfair+Display:ital,wght@0,400;0,600;1,400&display=swap" rel="stylesheet">
```

## Assumptions & Decisions

1. **字体回退**: 统一使用 'Microsoft YaHei' 作为主字体，fallback 为 sans-serif
2. **英文字体**: 使用微软雅黑，它本身支持英文显示，清晰现代
3. **无需区分标题和正文**: 用户要求"全部统一"，所以两种字体变量使用相同值
4. **保留 font-weight**: 不改变字重设置，保持标题加粗效果

3. ✅ 检查字体大小是否保持不变
4. ✅ 检查是否有任何排版问题
5. ✅ 推送到 GitHub 并在线验证

## Impact Analysis

**优点:**
- 字体统一，更简洁专业
- 减少外部字体加载，提升网站加载速度
- 微软雅黑是 Windows 系统自带字体，无需下载
- 中文显示效果优秀

**风险:**
- 非 Windows 系统（如 macOS、Linux）可能需要系统回退字体
- Playfair Display 的独特设计感会消失
- Inter 字体的现代感会消失

**缓解措施:**
- Fallback 到 sans-serif，系统会使用默认无衬线字体
